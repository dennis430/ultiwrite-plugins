# Ultiwrite Underwriting Coherence

Apply the asymmetric diligence engine (with document forensics) to underwriting evidence. Focus on whether the record coheres: identities, entities, documents, transactions, and claimed economics.

Document forensics and provenance checks establish what the evidence can support. The engine connects facts and tests assumptions rather than clearing individual artifacts in isolation.

Use the same MCP tools as commercial diligence. Do not invent findings. Surface ranked findings, source evidence, and the questions that affect boarding or funding. A clean point-check does not equal a coherent operating picture. The numbers may reconcile while the underlying assumption does not.

Use the canonical workflow in `../ultiwrite/SKILL.md`. Check the actual tool schemas, use only returned evidence, and do not treat a specialist skill as a separate product or engine.
