# Ultiwrite ChatGPT plugin package

Version 0.7.2. Publisher: DWS Offshore Fund. This directory is the ZIP source for contract `ultiwrite-mcp-evidence@7`.

The production MCP endpoint is `https://dwsoffshorepartners.com/api/integrations/ultiwrite/mcp`. This package does not prove a ChatGPT host install, an OpenAI directory upload, or a directory approval. Use the existing Ultiwrite plugin entry. This package does not create or replace a listing.

Rebuild only this archive with `node scripts/pack-chatgpt-plugin.mjs`. That command writes `release/ultiwrite-chatgpt-plugin-0.7.2.zip` and updates its checksum inventory without rebuilding other host packages. A built ZIP is not an installed integration.

The product is Ultiwrite — Asymmetric Diligence Engine; the category is Commercial Diligence; DWS Offshore Fund is the legal publisher. This adapter uses the shared DWS upload, evidence, comprehensive-report and publication controls. File submission accepts ChatGPT file objects from `files.oaiusercontent.com` with explicit `ultiwrite:evidence` consent and existing account allowance, including supported ZIP evidence packages. Processing and review states remain visible; a saved submission is not a completed assessment or a report release.

`ultiwrite_capabilities_get` exposes the public pricing from the existing offer registry (first completed analysis $0.00 with the full applicable analysis and full report before public launch; contact us for further-analysis pricing; no card required and no automatic charge) and the account links. Requests do not commission work, take payment or create accounts. Released reports provide authenticated website report, sign-in and entitled download links. No public report access, presigned URL or binary file fetch is created.

No credential belongs here. `mcp.json` names the canonical production endpoint, contains no server headers or client credential, and does not authorize deployment. The portable MCP server entry contains only its transport type and existing URL. OAuth requirements, registration and scopes are discovered from the service; the user still completes Ultiwrite sign-in and evidence consent. Per-server `extensions` are omitted because native clients reject that unsupported field before loading tools. The logo is `assets/logo.png`. No ChatGPT UI screenshot is supplied because the plugin has no custom UI.

`node scripts/pack-chatgpt-plugin.mjs --check` verifies this package against source. Historical 0.7.1 archives remain unchanged. A parser compatibility check does not establish an actual client connection or completed assessment. Do not publish to npm, submit a directory listing, or deploy the website from this repository.
