# Ultiwrite — Asymmetric Diligence

Standard inputs. A wider investigation.

Ultiwrite connects documents and evidence with independent verification to investigate businesses, counterparties, financings, acquisitions and portfolios. This EmDash connector puts the connection to that investigative workflow inside your CMS admin.

## What you can do

- Check the connected Ultiwrite account and its usage.
- Browse cases and released reports with pagination.
- Retrieve a saved Decision Brief by case or report ID.
- Create a private, single-use evidence-upload link and open the secure Ultiwrite uploader.
- Open available report pages in Ultiwrite for the full deliverable and entitled downloads.

Asymmetric diligence, investigative intelligence, business due diligence, document forensics and merchant risk are Ultiwrite service capabilities. This plugin is the thin connection to the service, not an embedded analysis engine.

## Deliberate access

No automatic submission of CMS content. No access to your posts, drafts, media or visitors. Administrators choose every outbound action. The API key is stored as an EmDash secret setting, and network access is limited to Ultiwrite's canonical domain.

An Ultiwrite account with explicit API approval is required for connected actions. Service usage follows the account's permissions, quota and plan. The uploader and report downloads open on Ultiwrite; report downloads require sign-in. This connector shows structured API responses, not a replacement for the complete report.
