# Microsoft schema snapshots

These unchanged public schema snapshots support reproducible offline structure validation. Source URLs:

- `app.schema.json`: https://developer.microsoft.com/json-schemas/teams/v1.28/MicrosoftTeams.schema.json
- `agent.schema.json`: https://developer.microsoft.com/json-schemas/copilot/declarative-agent/v1.9/schema.json
- `plugin.schema.json`: https://developer.microsoft.com/json-schemas/copilot/plugin/v2.4/schema.json

Retrieved November 1, 2026. Source and hashes are recorded in `sources.json` one directory above. These schemas are not included in the upload ZIP. Microsoft's platform validation adds checks beyond JSON Schema; use the current Agents Toolkit before submission.
