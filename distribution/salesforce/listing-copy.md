## Full description

Ultiwrite is an asymmetric diligence and investigative intelligence engine. Start with the documents behind a business, financing request, acquisition, property or portfolio. Ultiwrite investigates the available financial, identity, document-integrity, operational and external-context evidence, then reconciles the findings into a cohesive assessment.

This connector brings the existing Ultiwrite workflow into Agentforce. Users connect an Ultiwrite account, review current capabilities, submit the evidence they authorize, follow investigation status, and read saved findings and the Decision Brief. Report links return users to the same account for the available exports.

Use the assessment to identify corroboration, contradictions, implications, uncertainty and the next evidence request. A merchant file, acquisition packet or property document can start a broader investigation; each supported workflow is an application of the shared engine.

## Highlights

## Buyer requirements

An Ultiwrite account and its applicable permissions/allowance are required. The proposed first release uses an authenticated Agentforce Employee agent and per-user OAuth. Salesforce edition and add-on requirements depend on the customer's agent configuration. Optional Document Forensics follows the user's choice and account entitlement. The connector does not approve transactions, grant credit, process payments or promise a particular investigation result.
